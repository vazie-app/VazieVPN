# Vazie VPN 1.0.0 — Initial Public Release

The first release of Vazie VPN from its public repository, [vazie-app/VazieVPN](https://github.com/vazie-app/VazieVPN).

Vazie VPN is an Android client for your own VLESS configurations. It comes with no servers: you bring a configuration
or a subscription from your own server or provider.

## What's inside

- **Your configurations.** Paste a `vless://` link or a subscription link. REALITY and TLS, over TCP, WebSocket and
  gRPC. Review before saving; rename, duplicate, export, delete; latency next to each configuration.
- **On the device only.** Configurations are encrypted with a key held in the Android Keystore and never uploaded.
- **Connection.** One-tap connect and disconnect, the tunnel's state in a notification, split tunneling by app.
- **At hand.** Quick-connect and dashboard widgets, a Quick Settings tile, shortcuts for recent configurations.
- **Appearance.** Milk and Night Indigo themes, ten app icons, English and Russian.
- **Privacy.** No account, no ads, no analytics or crash-reporting SDKs. The app contacts the Vazie backend only to
  check for updates and to load the About links and common questions — with nothing about you or your configurations.

## Install

Requires Android 9 or newer (arm64-v8a or armeabi-v7a).

| File | For |
|---|---|
| `VazieVPN-universal.apk` | Any supported phone — choose this if unsure |
| `VazieVPN-arm64-v8a.apk` | Most phones from recent years |
| `VazieVPN-armeabi-v7a.apk` | Older 32-bit phones |

`libXray-v26.7.28-source.tar.gz` is the source of the VPN engine inside the APK, with every Go module it is built
from (GPL-3.0-or-later; see NOTICE.md). Verify the download against `SHA256SUMS.txt`. Every APK is signed with the certificate whose SHA-256 is listed in
`SIGNING_CERTIFICATE.txt`; this version installs as an update over earlier Vazie VPN builds signed with the same key.

## Known limitations

- VLESS only. VMess, Trojan, Shadowsocks, WireGuard and other protocols are not supported yet.
- No QR-code scanning: add a configuration by pasting its link.
- A subscription is downloaded once, when you add it; to refresh it, add the link again.
- Subscription links must use HTTPS.
- Phones only: no x86 builds and no Android TV.
