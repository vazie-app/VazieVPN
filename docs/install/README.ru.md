# Vazie VPN 1.0.0 — установка

В этом выпуске три вещи для установки:

| Файл | Что это |
|---|---|
| `VazieVPN-universal.apk` (а также `-arm64-v8a`, `-armeabi-v7a`) | Приложение для Android (Android 9 и новее) |
| `vazie-vpn-1.0.0-chromium.zip` | Расширение для Chrome, Edge, Brave, Vivaldi, Arc и других браузеров на Chromium на компьютере (Chrome 116 и новее) |
| `VazieVPNHelper.pkg` · `vazie-vpn-helper-windows-x64.exe` · `vazie-vpn-helper-linux-x64` | **Помощник**, который нужен расширению: один файл для вашей системы (macOS, Windows, Linux) |

Vazie VPN — клиент для **ваших собственных** конфигураций VLESS: серверов в нём нет, поэтому нужна ссылка `vless://` или ссылка-подписка от вашего сервера или провайдера.

Ни приложения, ни расширения пока нет в магазинах, поэтому оба ставятся из файла. Прежде чем что-то устанавливать, проверьте файл — это минута, и вы будете знать, что файл тот, что опубликовал Vazie.

> English version: [README.en.md](https://github.com/vazie-app/VazieVPN/releases/download/v1.0.0/README.en.md)

## 1. Проверьте файл

SHA-256 каждого файла указана в `SHA256SUMS.txt` в этом выпуске.

| Система | Команда |
|---|---|
| macOS, Linux | `shasum -a 256 vazie-vpn-1.0.0-chromium.zip` |
| Windows (PowerShell) | `Get-FileHash .\vazie-vpn-1.0.0-chromium.zip -Algorithm SHA256` |
| Windows (cmd) | `certutil -hashfile vazie-vpn-1.0.0-chromium.zip SHA256` |

Результат должен точно совпасть со строкой этого файла в `SHA256SUMS.txt`. Если не совпал — не устанавливайте: скачайте файл заново, а если снова не совпало, напишите на support@vazie.app.

APK ещё и подписан. Если на компьютере есть Android SDK, можно проверить, кто подписал:

```
apksigner verify --print-certs VazieVPN-universal.apk
```

Сертификат должен быть `CN=Vazie, OU=Application Signing, O=Vazovsky Development`, SHA-256 `970fbd4614aadaa171fb4c9aa58f6df0adad98c2c6d06252b5d3ad0d54f0a3aa` (он же в `SIGNING_CERTIFICATE.txt`).

## 2. Приложение для Android

Нужен Android 9 или новее. `VazieVPN-universal.apk` подходит любому поддерживаемому телефону; два других — меньшие сборки для 64-разрядных (`arm64-v8a`) и старых 32-разрядных (`armeabi-v7a`) телефонов.

1. Скачайте APK на телефон (или скопируйте на него с компьютера).
2. Откройте его. Если Android пишет, что установка из этого источника запрещена, нажмите **Настройки** и разрешите **Установку неизвестных приложений** для программы, из которой открыли файл (браузер или файловый менеджер). Потом это можно снова выключить.
3. Нажмите **Установить**.

Если Play Защита предупреждает о неизвестном разработчике: приложение новое и не в Google Play, поэтому Google ещё не знает разработчика. Сначала проверьте файл (раздел 1), затем **Подробнее → Всё равно установить**. Отключать Play Защиту не нужно.

Приложение подписано ключом выпусков Vazie, поэтому не ставится поверх сборок Vazie VPN, подписанных до 17.10.2026: такую сборку сначала удалите.

Откройте приложение, нажмите **Добавить конфигурацию**, вставьте ссылку `vless://` (или ссылку-подписку) и подключитесь. Android один раз спросит разрешение на настройку VPN.

## 3. Расширение для браузера

Расширение работает в браузерах на Chromium на компьютере: Chrome, Edge, Brave, Vivaldi, Arc, Dia, Opera, Yandex Browser, Chromium. В Chrome на телефоне, в Firefox и Safari оно не работает.

**Зачем помощник?** Расширение браузера не может само открыть VPN-туннель: оно не умеет запускать VPN-движок и слушать порт. Помощник — небольшая программа на вашем компьютере: она запускает вашу конфигурацию в Xray (тот же движок, что в приложении для Android) и открывает прокси, доступный только с вашего компьютера. Расширение направляет браузер на него и возвращает настройки браузера на место, когда вы отключаетесь. Через туннель идёт только браузер, остальные программы — нет.

### Шаг 1 — расширение

1. **Распакуйте** `vazie-vpn-1.0.0-chromium.zip` в папку, которую сохраните, например `Documents\VazieVPN`, — не в «Загрузки» и не во временную папку. Браузер запускает расширение прямо из этой папки. В ней должен лежать `manifest.json`.
2. Откройте страницу расширений и включите **Режим разработчика**:

   | Браузер | Адрес |
   |---|---|
   | Chrome | `chrome://extensions` |
   | Edge | `edge://extensions` |
   | Brave | `brave://extensions` |
   | Vivaldi | `vivaldi://extensions` |
   | Arc | `chrome://extensions` |

3. Нажмите **Загрузить распакованное расширение** и выберите папку из шага 1.
4. Нажмите значок с кусочком пазла рядом с адресной строкой и **закрепите** Vazie VPN.

При запуске браузер может напоминать, что включены расширения в режиме разработчика. Так браузер относится к любому расширению, установленному не из магазина; напоминание можно закрыть.

### Шаг 2 — помощник

Откройте Vazie VPN, затем **Настройки → Помощник**. Там одна кнопка с установщиком для вашей системы; файл можно взять и из этого выпуска. Дальше:

**macOS** — откройте `VazieVPNHelper.pkg` и следуйте установщику (Apple silicon и Intel). Установщик пока не подписан Apple, поэтому macOS может написать, что не может проверить разработчика: **нажмите на файл правой кнопкой и выберите «Открыть»** или откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**.

**Windows** — откройте `vazie-vpn-helper-windows-x64.exe`. Появится окно: оно установит помощника и скажет, когда всё готово; нажмите Enter, чтобы закрыть. Файл пока не подписан, поэтому SmartScreen может показать *«Windows защитила ваш компьютер»*: нажмите **«Подробнее» → «Выполнить в любом случае»**.

**Linux** — сделайте файл исполняемым и запустите:

```
chmod +x vazie-vpn-helper-linux-x64
./vazie-vpn-helper-linux-x64
```

Что делает установщик: сам находит расширение Vazie VPN в ваших браузерах (идентификатор расширения вводить не нужно), копирует помощника в вашу пользовательскую папку, регистрирует его в браузере и скачивает движок Xray из его собственного релиза, сверяя с SHA-256, зашитой в помощнике. Для скачивания нужен интернет; права администратора на Windows и Linux не нужны (установщик macOS, как любой установщик, спросит пароль, а затем настроит всё для вас, а не для администратора).

Вернитесь в расширение. **Оно само заметит помощника** — ничего нажимать не нужно. Если через минуту экран «Помощник» всё ещё просит установить его, нажмите **«Проверить снова»**.

### Шаг 3 — первое подключение

1. В расширении нажмите **+ Добавить** и вставьте ссылку `vless://` или ссылку-подписку. Для подписки браузер спросит разрешение обратиться к этому одному серверу; разрешите, и сразу после загрузки списка разрешение будет отозвано.
2. Проверьте, что прочитал Vazie VPN, дайте имя и **сохраните**.
3. Нажмите **Подключить**. Значок на панели показывает состояние.

Чтобы пустить через VPN только часть сайтов (или все, кроме некоторых), откройте **Настройки → Раздельное туннелирование**. Адреса вашей локальной сети (`localhost`, `192.168.x.x`, `.local`) никогда не идут через туннель.

### Обновление

Скачайте новый архив, распакуйте его **в ту же папку** (заменив файлы), откройте страницу расширений и нажмите кнопку **перезагрузки** (круговая стрелка) у Vazie VPN.

Не переносите и не переименовывайте папку: для браузера расширение из нового места — новое расширение.

### Удаление

- Расширение: нажмите **Удалить** на странице расширений.
- Помощник: запустите его с `uninstall`. macOS: `"$HOME/Library/Application Support/Vazie VPN/bin/vazie-vpn-host" uninstall`. Linux: `~/.local/share/vazie-vpn/bin/vazie-vpn-host uninstall`. Windows (cmd): `"%LOCALAPPDATA%\Vazie VPN\bin\vazie-vpn-host.exe" uninstall`. Это убирает регистрацию и скачанный движок.

## Проблемы и вопросы

- **Экран «Помощник» не находит помощника.** Установщик ищет расширение в ваших браузерах, поэтому сначала поставьте расширение; если делали наоборот — запустите установщик ещё раз. Затем нажмите **«Проверить снова»**. Если вашего браузера нет в списке (Chrome, Edge, Brave, Vivaldi, Arc, Dia, Opera, Yandex Browser, Chromium), напишите, какой это. Если расширение загружено из папки (как выше), оно должно быть уже загружено, когда вы запускаете установщик, — или запустите установщик ещё раз: id расширения он узнаёт из браузера.
- **«Не удалось установить движок».** Для скачивания нужен интернет и `github.com`. Нажмите **«Установить движок»** на экране «Помощник», когда будете онлайн.
- **«Прокси браузера занят».** Настройками прокси управляет другое расширение или политика организации; Vazie VPN их никогда не перехватывает. Отключите другое.
- **Файл не совпал с контрольной суммой** — скачайте заново, а если снова не совпал, напишите на support@vazie.app.
- **Что-то не работает** — support@vazie.app или раздел «Обратная связь» на экране «О приложении». Проблема безопасности: [SECURITY.md](https://github.com/vazie-app/VazieVPN/blob/main/SECURITY.md). Никогда не публикуйте настоящую конфигурацию или ссылку `vless://` — это учётные данные.

Расширение и помощник проверены целиком на macOS (Apple silicon). Сборки для Windows и Linux делает и тестирует workflow выпуска, но человек их ещё не запускал; сообщайте, что найдёте.

Что расширение защищает и что сознательно нет: [модель угроз](https://github.com/vazie-app/VazieVPN/blob/main/docs/security/EXTENSION_THREAT_MODEL.md).
