# Vazie VPN

**Спокойный клиент для ваших собственных конфигураций VLESS — на Android и в браузере.**

Принесите конфигурацию или подписку со своего сервера или от своего провайдера. Vazie VPN хранит её зашифрованной на
вашем устройстве и подключается одним нажатием — без аккаунта, рекламы и аналитики.

[Приложение для Android](apps/android/README.ru.md) · [Расширение для браузера](apps/browser-extension/README.md) · [vazie.app](https://vazie.app)

## Что в репозитории

| | |
|---|---|
| [`apps/android`](apps/android) | Приложение для Android: VLESS поверх REALITY и TLS (TCP, WebSocket, gRPC), подписки, раздельное туннелирование по приложениям, виджеты, плитка быстрых настроек. |
| [`apps/browser-extension`](apps/browser-extension) | То же приложение как расширение для Chromium (Manifest V3): конфигурации, подписки, задержка, раздельное туннелирование по сайтам, темы, значки, руководства, FAQ, русский и английский. |
| [`apps/native-host`](apps/native-host) | Помощник, который запускает расширение через native messaging. Он запускает Xray — тот же движок, что встроен в приложение для Android, — на прокси, доступном только с этого компьютера. |
| [`shared/vless-vectors`](shared/vless-vectors) | Набор ссылок, которые оба парсера обязаны читать одинаково. |
| [`docs`](docs) | Решения и модели угроз, общие для клиентов. |

Vazie VPN — клиент. Серверов в комплекте нет: он подключается к серверу VLESS, который у вас уже есть.

## Установка

Всё лежит в [последнем выпуске](https://github.com/vazie-app/VazieVPN/releases/latest); полная инструкция — с проверкой
файлов и разбором проблем — в [docs/install/README.ru.md](docs/install/README.ru.md).

**Android** (9 и новее): скачайте `VazieVPN-universal.apk`, откройте, при запросе разрешите установку из файла, добавьте
ссылку `vless://` или подписку, подключитесь.

**Браузер** (Chrome, Edge, Brave, Vivaldi, Arc — Chrome 116 и новее), в два шага:

1. **Расширение.** Распакуйте `vazie-vpn-1.0.0-chromium.zip` в папку, которую сохраните, откройте `chrome://extensions`,
   включите *Режим разработчика*, **«Загрузить распакованное»**, выберите папку, закрепите Vazie VPN.
2. **Помощник.** Браузер не может сам открыть туннель, поэтому у расширения есть небольшая программа на вашем
   компьютере: она запускает вашу конфигурацию в Xray на прокси, доступном только с вашего компьютера. Откройте Vazie VPN →
   **Настройки → Помощник**: одна кнопка скачает установщик для вашей системы (`VazieVPNHelper.pkg` для macOS,
   `vazie-vpn-helper-windows-x64.exe`, `vazie-vpn-helper-linux-x64`). Откройте его — и всё: он сам найдёт расширение,
   зарегистрируется в браузере и скачает движок (проверяется по зафиксированной SHA-256). Расширение заметит, когда всё
   готово.

Файлы пока не подписаны: macOS скажет, что не может проверить разработчика (правый клик → «Открыть»), Windows SmartScreen —
«Подробнее → Выполнить в любом случае». Сначала сверьте каждый файл с `SHA256SUMS.txt`. Из исходников: у `apps/native-host`
и `apps/browser-extension` свои README.

Устройство — в [ADR 0002](docs/adr/0002-browser-extension.md); что расширение защищает и что сознательно нет — в
[модели угроз](docs/security/EXTENSION_THREAT_MODEL.md).

Устройство — в [ADR 0002](docs/adr/0002-browser-extension.md); что защищено и что сознательно нет — в
[модели угроз](docs/security/EXTENSION_THREAT_MODEL.md).

## Конфиденциальность

Аккаунта нет. Конфигурации остаются на устройстве, зашифрованными ключом платформы, и никуда не выгружаются. Нет
аналитики, отчётов о сбоях, рекламы и слежки. Клиенты обращаются только к бэкенду Vazie — за проверкой версии (только
Android), ссылками раздела «О приложении» и ответами на частые вопросы, — и ничего не сообщают о вас, устройстве или
конфигурациях. Ссылка-подписка скачивается напрямую с её собственного сервера по HTTPS.
